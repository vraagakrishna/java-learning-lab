# Java Practice Tasks

> Draft based on the Java source available for review. Before replacing the original README task section, compare this list with that section and retain every original requirement.

1. Read country and region records from `countries.csv`.
2. Validate records and skip malformed rows.
3. Filter records where population is greater than 50,000,000 and area is greater than 100,000 km².
4. Calculate total and average population.
5. Calculate total and average area.
6. Identify the region with the largest area.
7. Identify the region with the highest population.
8. Group regions by country and sort country names and region names alphabetically.
9. Write summary statistics and region data to `results.json`.
